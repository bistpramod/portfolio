# Pramod Bist — Digital Marketing Portfolio

A responsive personal portfolio focused on Pramod's practical digital marketing experience, paid media work, analytics toolkit, search fundamentals and education.

## Stack

- React 19 + TypeScript
- Framer Motion
- Lucide React
- Vite

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production files are generated in `dist/`. The existing GitHub Actions workflow publishes that directory to GitHub Pages when changes are pushed to `main`.
